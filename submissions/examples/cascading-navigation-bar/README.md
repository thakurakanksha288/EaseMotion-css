# Cascading Navigation Bar Component

A beautiful, lightweight, and accessible navigation bar component featuring smooth cascading motion effects and Neumorphic aesthetics. Built natively for the **EaseMotion CSS** UI Library.

## Features
- **100% Pure CSS:** No JavaScript execution overhead. Uses a non-blocking CSS checkbox pattern for interactivity.
- **Cascading Motion:** Items gracefully transition downward with an automatic staggered delay utilizing CSS runtime calculation variables (`calc()`).
- **Neumorphic Aesthetic:** Built with precise flat and inset box-shadow rules to simulate modern soft UI properties.
- **Fully Responsive:** Smooth transformation from a desktop row layout to an accessible vertical cascade on smaller breakpoints.
