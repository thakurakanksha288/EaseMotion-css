# Animated Skeleton Card Showcase

A clean, modern, pure HTML & CSS implementation of an animated skeleton loading card pattern. It mimics a dashboard/e-commerce layout structure to enhance perceived user experience while content fetches asynchronously.

## Features
- **Hardware-Accelerated Performance:** Uses pure CSS gradients and background positions over heavy animations to avoid page stutters.
- **Fluid Shimmer:** Smooth, infinite `linear-gradient` transition loop.
- **Modern UI Elements:** Covers image, header line text block, secondary body lines, and an interactive action element block placeholder.
- **Responsive Layout:** Automatically scales from mobile screen sizes up to full desktop grids.
- **Standalone Delivery:** No external framework requirements, icons, or JavaScript inclusions.
