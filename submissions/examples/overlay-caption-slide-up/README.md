# Overlay Caption Slide-Up

A lightweight, CSS-only interaction that smoothly slides an image caption into view from the bottom when hovered.

## Usage

1. Copy the HTML structure:
```html
<div class="overlay-slide">
  <img src="your-image.jpg" alt="Description">
  <div class="caption-panel">
    <h4>Title</h4>
    <p>Subtitle or description here.</p>
  </div>
</div>
